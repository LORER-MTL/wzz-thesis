\chapter*{ABSTRACT}\thispagestyle{headings}

\begin{otherlanguage}{english}

Modelling languages for convex optimization let users state problems in a form close to the
mathematics, and compile them into the numerical data that solvers accept. In \texttt{CVXPY}, a
widely used modelling language, most of the compilation time is spent converting symbolic
expression trees into the sparse constraint and objective matrices. Because the constraint matrix
is a Jacobian and the objective matrix is a Hessian, the conversion can be viewed as a sparse
differentiation problem. We present \texttt{SparseDiffEngine}, a lightweight open-source C library
that computes the Jacobian and the Hessian directly from the expression structure. The computation
has two phases. A symbolic pass runs once per problem and determines the sparsity patterns of the
matrices. A numeric pass fills new values into the fixed patterns at every solve. Re-solving a
parametrized problem therefore costs only one numeric pass. Using \texttt{SparseDiffEngine}, we
implement a new way to form the numerical data in \texttt{CVXPY}. This two-phase approach is an
alternative to \texttt{CVXPY}'s existing caching of parametrized problems, and it places no
restriction on how the parameters enter the problem. We compare this new approach with
\texttt{CVXPY}'s three current implementations on a public benchmark suite of $25$ problems. The
first compilation is the fastest on $21$ of the $25$ problems, with a geometric-mean speedup of
$2.8\times$ over the best current implementation. Re-solves of parametrized problems run at times
comparable to those of \texttt{CVXPY}'s existing caching.

\end{otherlanguage}
