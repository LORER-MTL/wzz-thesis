\Chapter{A lightweight canonicalization engine}\label{sec:Theme1}

Fundamentally, there is not much difference between how \texttt{SparseDiffEngine}
computes derivatives and CVXPY's canonicalization backend. However, there are many
interesting implementation details which we will present in this chapter.
Firstly the use of a custom sparse matrix data structure allows a natural split
between the symbolic and numeric phase of the derivative computation. This separation
turns out to be very useful for compiling problems involving parameters, where
the structure is fixed but the numerical values can change.
Secondly, in addition to being sparse, the problem data of most optimization
problems also have a lot of structure such as dense blocks or diagonal copies.
In \texttt{SparseDiffEngine} we introduce two new matrix classes: \texttt{permuted-dense}
and \texttt{stacked-permuted-dense} for this purpose, they enable us to make
use of dense BLAS subroutines when possible and also save unnecessary data copies.

The rest of the chapter is structure as follows: we begin with a brief overview of
fundamental data structures. This covers basics like an expression and an atom,
as well as more complicated matrix classes.
Notably we will focus much of our attention on the \texttt{permuted-dense}
matrix which is often used. Next we describe the algorithms, or \emph{kernels},
which allow us to compose and operate on these data structures and matrices.
Rather than attempting to explain too much, the exposition will be more about
the organization of the code and how we handle operations between different
types of matrices. An intrigued reader will certainly learn a lot more
from exploring the repository, which is open source.
Finally, the chapter will end with some comments about the application
programming interface (API) of \texttt{SparseDiffEngine} as well as how it
is being called in CVXPY.
